# Company-level Datasets

The BGI team requires more and deeper data at the company level. We will build these datasets from third-party sources (e.g. publicly available data) as well as data we build from BGI's own data sources. We'll focus on the Fortune 1000 but aim to build data for a more complete company universe.

Finally, we'll create robust crosswalks to address company subsidiaries.

## Third-Party Data

* [Company metadata on Fortune 1000](https://docs.google.com/spreadsheets/d/1bPmjuInVp3Mk2cvd00Q_9JKagoWv6BC5d2r_MNnFo4k/edit#gid=2087503401) (2022, Kaggle)
* [Diversity of company’s Boards](https://hub.onmogul.com/hubfs/Fortune500BoardDiversity2022.pdf) (2021, Mogul)
* [Fortune 1000 companies’ tech stacks](https://docs.google.com/spreadsheets/d/1SxtB-72PyG_YUhtsMTT7LMR6x6iaoME2/edit#gid=1546909821) (2022)
* [USPTO Patent filings by company](https://www.uspto.gov/web/offices/ac/ido/oeip/taf/topo_20.htm#PartB) (2020, USPTO)
* [Economic Policy Institute Select Wage data](https://docs.google.com/spreadsheets/d/19I8H3x1VhU11YTWP8jyeiu3oO4FJBpOoONZLLNHtsHU/edit#gid=0) ([Company Wage Tracker](https://www.epi.org/company-wage-tracker/), 2022)
* Headquarters locations (Need dataset)
* Company age (Need dataset)
